# Мегдан

Мултиплейър мини игри за приятели: стаи с 4-буквен код, ходови игри, чат, ELO класация.
Две версии от един и същ код:
- **Сайт (основната):** https://kaloyan05.github.io/Megdan/ — без регистрация, приятелят натиска линка, пише име и е в стаята. Данни: Firebase (проект `megdan-f5985`).
- **Артефакт в claude.ai:** https://claude.ai/artifact/46Gt4GYPKn9nDFjjVayBvA — изисква вход в claude.ai.

Игри (16): Четири в редица, Реверси, Точки и кутийки, Цветна осмица (с +4 и „Последна карта!“), Ултимат морски шах, Покер със зарове, Мемори, Не се сърди човече, Табла, Морски бой, Мини голф, Дама, Викторина, Реакция-рали, а на живо: Понг и Въздушен хокей.

Още: игра срещу бот (3 нива), Вечер на игрите (серия от 3 или 5 игри с шампион), вариации на правилата, „Ти срещу приятел“ в класацията, автоматично почистване на стаи след 14 дни без активност.

## Как да поканиш приятел

**На сайта:** в стаята натисни „Покани приятел“ и прати линка (Viber, Messenger…). Приятелят пише името си и влиза направо в стаята, вече „Готов“.

**В артефакта в claude.ai:**
1. Отвори артефакта и натисни **Share**.
2. Покани приятеля **по имейл с право „Can edit“**. Хората извън твоята организация пишат в базата само с това право.
3. **Не включвай „Anyone with the link“.** Докато има публичен линк, поканените отвън не могат да пишат.
4. Приятелят трябва да е влязъл в claude.ai. Най-сигурно е да отвори линка в браузъра на телефона.
5. В стаята докосни жълтата табелка „Покани“ с кода и прати копираната покана. Линкът води направо в стаята.

## Разработка

```
npm test                 # unit тестове (node --test)
npm run dev              # http://localhost:8080/?store=local&as=p1  (втори таб: &as=p2; &lag=120 = мрежово забавяне)
npm run build            # dist/index.html — целият JS вграден в една страница
node e2e/all-games.mjs   # цяла партида от всяка ходова игра през интерфейса (Playwright)
node e2e/bots.mjs        # всяка ходова игра срещу бот
node e2e/live.mjs        # Понг и Хокей: срещу бот и двама в отделни табове
node e2e/series.mjs      # Вечер на игрите
node e2e/connect4.mjs    # стая, код, реванш, презареждане, класация, „Ти срещу“
```

С `?store=local` всичко работи без claude.ai: данните са в localStorage, а табовете се синхронизират през BroadcastChannel.

## Сайтът (GitHub Pages + Firebase)

```
npm run build && ./deploy.sh   # строи dist/site/ и го качва в клона gh-pages
```

- `src/site-config.js`: адресът на сайта и firebaseConfig. `build.mjs` прави два бъилда с флага `__SITE__`.
- `src/net/store-firebase.js`: анонимен вход (постоянен uid на устройство), Firestore за документите, Realtime Database за присъствие и игрите на живо.
- Правилата са във `firebase/`: `firestore.rules` и `database.rules.json` — копират се в конзолата на Firebase.
- Нужно във Firebase: Authentication → Anonymous; Firestore; Realtime Database (europe-west1, иначе смени `databaseURL`).
- `FIREBASE=1 BASE=https://kaloyan05.github.io/Megdan/ PAGE= node e2e/invite.mjs` проверява поканата срещу истинския Firebase.

## Структура

- `src/core/`: RNG със seed, replay на лога с ходове, ELO, ботове, серии.
- `src/games/`: по един файл на игра с общия интерфейс (`init`, `validateMove`, `applyMove`, `currentPlayer`, `autoMove`, `isOver`, `winner`, `render`).
- `src/games/live.js`: основа за игрите на живо (присъствие в именувана стая, канвас, вход от пръст/мишка/стрелки).
- `src/net/`: store адаптери (claude.ai db/user/room/sample или локален) и `api.js` с операциите за стаи, ходове, чат, ботове, серии и статистика.
- `src/ui/`: профил, лоби, стая, класация, звуци.

Подробности: `SPEC.md`, `tasks/plan.md`.

## Известни ограничения

- Данните на стаята са видими за всички в нея: при картите и заровете технически подкован играч може да изчисли скрита информация. Морски бой е защитен (личен флот + проверка с хеш).
- Ако играч си тръгне по средата на партида без таймер, останалите могат да се предадат или да започнат нова. С таймер ходовете му се играят автоматично.
- Работата вътре в мобилното приложение Claude не е проверена. Браузърът на телефона е сигурният път.
- Игрите на живо спират, ако единият играч излезе. Колкото по-бавен е интернетът, толкова по-бавно лети топката.
